# 中华减脂厨房 · China Cut Kitchen

> 把中国八大菜系的风味基因装进减脂饭盒。
> A macro-driven cookbook for cutting, with regional Chinese flair.

一个**纯前端、单文件、零依赖**的减脂饮食工具。设定每日宏量目标,选择想吃的地方菜系,系统会用当地常见食材为你编排三餐,提供详细做法,并实时对照中国/美国膳食指南检查你的菜单是否均衡。

## 🧭 全局设计

### 抽屉式导航菜单
默认收起,左上角浮动一个 ☰ 汉堡按钮。点击滑出 240px 宽侧栏,带半透明遮罩 + 模糊背景。5 大章节(营养目标 / 地区菜系 / 食材库 / 今日菜单 / 指南达标)+ 食材换算器工具一键直达。滚动时自动高亮当前章节。三种关闭方式:点关闭按钮 / 点遮罩 / 按 ESC,或点击章节链接自动平滑滚动到目标后关闭。

### 顶部工具栏
顶部 masthead 提供三个高频入口:
- **食材换算器** — 同类食材等量互换
- **导出菜单** — 一键导出 PNG 长图
- **访问量** — 总访问量 + 今日访问量(小字低调显示)

### 个人偏好持久化
所有个人偏好**自动保存到本设备 localStorage**,下次打开同一浏览器自动还原:
- 每日总代谢(TDEE)与热量缺口百分比
- 训练日 / 非训练日 / 自定义模式选择
- 自定义模式下的碳水/蛋白/脂肪三大宏量比例
- 选择的菜系与子地区(如粤菜→潮汕)
- 中国指南 / 美国指南选择

侧栏底部 SAVED 徽章会在保存时短暂闪烁,确认偏好已写入。隐私上,所有数据**只存在你自己的浏览器**,不上传任何服务器。

## ✨ 核心功能

### 🎯 Chapter 01 · 每日营养目标

设定每日总代谢与热量缺口,自动换算碳水/蛋白质/脂肪三大宏量目标:

- **三种宏量模式**
  - 训练日(50C / 30P / 20F)
  - 非训练日(35C / 35P / 30F)
  - 自定义(三个滑块自由调节,自动校验合计 100%)
- TDEE 输入 + 0–30% 热量缺口滑块
- 实时显示总摄入 + 三大宏量克数与对应热量

### 🍜 Chapter 02 · 八大菜系 + 子地区

覆盖中国八大菜系及其代表性子地区:

| 菜系 | 子地区 | 代表做法 |
|------|--------|----------|
| 粤菜 | 广府 / 潮汕 / 客家 | 白灼、清蒸、滚汤、上汤、卤水 |
| 川菜 | 成都 / 重庆 / 自贡 | 水煮、干煸、宫保、鱼香、麻婆 |
| 苏菜 | 淮扬 / 金陵 / 苏锡 | 清炖、白煮、盐水煮、卤煮 |
| 京菜 | 宫廷 / 家常 | 清汤涮、京酱、白煮 |
| 东北菜 | 辽 / 吉 / 龙 | 锅烹、酸菜煮、清炖 |
| 湘菜 | 湘江 / 洞庭 | 剁椒蒸、湘式小炒、酸辣 |
| 浙菜 | 杭帮 / 甬帮 / 绍兴 | 白切、糟溜、咸鲜、西湖醋 |
| 闽菜 | 福州 / 闽南 | 清汤、白灼、清蒸 |

切换菜系会同步影响:
- 食材库当地常用食材**置顶**(全部仍可见可搜)
- 菜单生成时优先使用本地食材
- 烹饪手法切换为本地代表性做法
- 子地区进一步细化口味(成都偏宫保鱼香,重庆偏水煮干煸)

### 🥬 Chapter 03 · 食材营养库(默认折叠)

90+ 种常见食材,每项标注:

- 每 100g 生重的热量与三大宏量
- 食材分类(碳水 / 蛋白 / 脂肪 / 蔬菜)
- 当地常用区域(影响置顶顺序)
- 中/美膳食指南分组(影响指南推荐量标签)
- 常用份量参考(一碗/一颗/一份)
- 深色蔬菜标记(用于指南达标计算)

**折叠机制**:为避免长列表占据视线,食材库**默认只展示前 4 行**(根据屏宽动态计算每行卡数),底部带渐变蒙层。点击"展开剩余 X 项"按钮可看完整库;每个分类筛选(全部/碳水/蛋白/脂肪/蔬菜)独立记忆展开状态;搜索时自动展开,清空搜索回到折叠。

涵盖范围:

- **蛋白(肉/蛋/奶/豆)**:鸡胸/腿、瘦牛肉、猪瘦肉、鸭胸、瘦羊肉、鸡蛋、蛋白、纯/脱脂牛奶、希腊酸奶、低脂奶酪、莫扎瑞拉、嫩/老豆腐、豆干、无糖豆浆、鹰嘴豆、毛豆
- **鱼类水产**:鲈鱼、鳕鱼、三文鱼、巴沙鱼、龙利鱼、鲳鱼、带鱼、鲷鱼、金枪鱼、罗非鱼、草鱼、黄花鱼、鲫鱼、鲢鱼、鲜虾、鱿鱼、蛤蜊、烟熏三文鱼、金枪鱼罐头

### ⇌ 食材换算器(顶部快捷)

顶部"食材换算器"按钮一键唤出,**主导宏量等量换算**,解决"今天没土豆,糙米饭多少克才能替代"这类日常问题。

四大换算类别:
| 类别 | 换算依据 | 默认基准 |
|------|----------|----------|
| 碳水类 ↔ 碳水类 | 主比**碳水克数** | 130g 糙米饭 |
| 蛋白质类 ↔ 蛋白质类 | 主比**蛋白克数** | 100g 鸡胸肉 |
| 脂肪源 ↔ 脂肪源 | 主比**脂肪克数** | 20g 巴旦木 |
| 蔬菜类 ↔ 蔬菜类 | 主比**重量** | 200g 西兰花 |

仅支持同大类互换(碳水换碳水,不会跨类换成蛋白)。

界面包含:
- **左右双栏对照**:输入 FROM 食材克数,自动算出 TO 食材的等量克数 + 完整营养差异
- **常用替换 6 张快捷卡**:点选直接切换 TO 食材
- **同类食材一览表**:列出当前类别下所有食材的等量克数,按份量升序排列,一目了然知道"换成 X 要吃几克",并对比热量

例如:
- `130g 糙米饭(含碳水 ~32g)` ⇌ `~160g 土豆 / ~155g 红薯 / ~145g 玉米 / ~290g 山药`
- `100g 鸡胸(含蛋白 ~24g)` ⇌ `~109g 鳕鱼 / ~119g 巴沙鱼 / ~120g 罗非鱼`

### 📋 Chapter 04 · 今日菜单(三种模式)

#### A. 自动生成 · 每日不同
- **种子化随机**:同一天 + 同一菜系组合下,刷新页面得到完全相同的菜单(基于日期哈希)
- 日期选择器:改日期自动换菜单
- "↻ 换一份"按钮:同一天想换搭配也行
- 三餐分配 25% / 40% / 35%,主食 + 蛋白菜 + 蔬菜菜 + 偶尔水果
- 自动微调份量逼近宏量目标
- 脂肪不足时自动补加坚果

#### B. 按食材自定义
- 左侧食材池,按菜系置顶常用,可搜索/分类筛选
- 右侧已选食材列表,克数可直接输入调整
- 三餐独立管理(早/午/晚)
- **智能推荐**:基于已选食材,自动推荐当前菜系下的菜品组合
  - 选了鸡胸 → 推荐"水煮鸡胸 / 凉拌鸡胸 / 清蒸鸡胸"
  - 选了西兰花 → 推荐"白灼西兰花 / 蒜蓉蒸西兰花 / 上汤西兰花"
- 实时合计三餐营养并对比目标

#### C. 按菜品自定义
- 60+ 道预设菜品库,按当前菜系动态生成
- 每张菜品卡显示菜名、做法、营养值
- 分类筛选:全部 / 主食 / 蛋白菜 / 蔬菜菜 / 汤品 / ★当地
- 点选菜品 → 加入指定餐次
- 实时三餐预览 + 合计

### 🍳 烹饪卡片 Modal

点击任意菜名弹出详细做法卡:

- **菜品信息**:中英文名、做法标签、所属菜系
- **核心数据**:耗时、总热量、三大宏量
- **完整原料清单**:主料精确克数 + 辅料(姜葱蒜/调料/酱汁)
- **分步做法**:每个做法都为减脂版定制
  - 水煮菜:"激而不泡",省去最后淋油可减 30% 热量
  - 麻婆豆腐:用清汤替代肉末
  - 干煸豆角:用不粘锅 + 耐心煸炒,油量减半以上
  - 凯撒沙拉:希腊酸奶替代蛋黄油基酱
- **减脂要点**:讲清传统做法 vs 减脂版的差异

30+ 种烹饪手法均有完整步骤和贴士,包含西式油醋凉拌、凯撒拌、希腊式等沙拉做法。

### 📤 菜单导出为 PNG

两个入口(顶部 masthead + 第四章右上角),点击弹出选择 modal:

- ☑ 三餐菜单 — 早午晚 + 各菜品 + 食材克数 + 单餐营养
- ☑ 全日营养合计 — 总热量 / 三大宏量对照目标 + 达标徽章
- ☐ 膳食指南达标 — 完整食物组对照表(可选)

**技术亮点 — 零依赖 PNG 导出**:
- 不引第三方库(html2canvas / dom-to-image / jsPDF 都没用)
- 全程纯 SVG 手绘:headerline + meal block + total bar + guide table + footer 五种 block
- SVG 序列化 → Blob → 转 data URL → `<canvas>` → `canvas.toBlob('image/png')` → 触发下载
- **2x 缩放**(retina 清晰度,实际输出 1600px 宽)
- 字体使用系统 fallback(Songti SC / PingFang SC / Microsoft YaHei),避免 canvas tainted 跨域问题
- 文件名自动包含菜系英文 + 日期:`China-Cut-Kitchen-Cantonese-2026-05-03.png`

整体延续杂志 editorial 风格,黑白米色 + 锈红 / 深绿 / 焦糖三色识别,印出来或者发朋友圈都体面。

### 📖 Chapter 05 · 膳食指南达标

支持中/美两套权威膳食指南实时核对:

#### 中国指南(中国营养学会 2022 版平衡膳食宝塔,1600–2400 kcal)
12 个食物组 × 推荐摄入区间:
- 精制谷类 50–150g + 全谷物杂豆 50–150g
- 薯类 50–100g
- 深色蔬菜 ≥150g(占总蔬菜 ≥1/2) + 浅色蔬菜
- 水果 200–350g
- 畜禽肉 40–75g · 鱼虾 40–75g · 蛋 40–50g
- 奶类 300–500ml · 大豆 15–25g · 坚果 5–10g

#### 美国指南(USDA Dietary Guidelines for Americans 2020-2025,Healthy U.S.-Style 2000 kcal)
11 个食物组:
- 蔬菜 2.5 cup-eq · 水果 2 cup-eq
- 全谷物 ≥3 oz-eq / 总谷物 6 oz-eq
- 乳制品 3 cup-eq
- 蛋白质合计 5.5 oz-eq(含海鲜 ~8 oz/周)
- 油 27g

每个食物组实时显示:
- 当前菜单实际摄入量
- 推荐区间 + 进度条
- 状态徽章(✓达标 / ⌣不足 / ⚠超量)
- 综合达标率(Compliance Score)

干重/熟重已自动换算(豆腐 100g → 大豆 15g 当量、糙米饭 130g → 干重 52g 等)。

### 📊 访问量统计

顶部 masthead 右侧小字显示**总访问量 + 今日访问量**,低调不抢戏。

技术方案(零运维 + 高可用):
- **主端点**:[abacus.jasoncameron.dev](https://abacus.jasoncameron.dev) — CountAPI 已知后继者,免费、CORS 开放、无需账号
- **备选端点**:[counterapi.dev](https://counterapi.dev) v1 / v2(自动失败 fallback)
- **最终 fallback**:localStorage 单设备计数(全部公共服务失败时启用)
- **会话去重**:sessionStorage 标记,同一会话内刷新页面不重复 +1
- **今日访问**:按日期 key 自动按天分桶,过零点自动新建桶
- **隐私友好**:计数服务不存 IP、不下 cookie、纯增量计数器

## 🚀 快速开始

### 方式 1:本地打开
```bash
git clone https://github.com/<your-username>/china-cut-kitchen.git
cd china-cut-kitchen

open china-diet-kitchen.html      # macOS
```
