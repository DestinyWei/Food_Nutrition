# 中华减脂厨房 · China Cut Kitchen

> 把中国八大菜系的风味基因装进减脂饭盒。
> A macro-driven cookbook for cutting, with regional Chinese flair.

一个**纯前端、单文件、零依赖**的减脂饮食工具。设定每日宏量目标,选择想吃的地方菜系,系统会用当地常见食材为你编排三餐,提供详细做法,并实时对照中国/美国膳食指南检查你的菜单是否均衡。

## ✨ 核心功能

### 🎯 Chapter 01 · 每日营养目标

设定每日总代谢与热量缺口,自动换算碳水/蛋白质/脂肪三大宏量目标:

- **三种宏量模式**
  - 训练日(50C / 30P / 20F)
  - 非训练日(35C / 35P / 30F)
  - 自定义(三个滑块自由调节,自动校验合计 100%)
- TDEE 输入 + 0–30% 热量缺口滑块
- 实时显示总摄入 + 三大宏量克数与对应热量

### 🍜 Chapter 02 · 八大菜系 + 子地区

覆盖中国八大菜系及其代表性子地区:

| 菜系 | 子地区 | 代表做法 |
|------|--------|----------|
| 粤菜 | 广府 / 潮汕 / 客家 | 白灼、清蒸、滚汤、上汤、卤水 |
| 川菜 | 成都 / 重庆 / 自贡 | 水煮、干煸、宫保、鱼香、麻婆 |
| 苏菜 | 淮扬 / 金陵 / 苏锡 | 清炖、白煮、盐水煮、卤煮 |
| 京菜 | 宫廷 / 家常 | 清汤涮、京酱、白煮 |
| 东北菜 | 辽 / 吉 / 龙 | 锅烹、酸菜煮、清炖 |
| 湘菜 | 湘江 / 洞庭 | 剁椒蒸、湘式小炒、酸辣 |
| 浙菜 | 杭帮 / 甬帮 / 绍兴 | 白切、糟溜、咸鲜、西湖醋 |
| 闽菜 | 福州 / 闽南 | 清汤、白灼、清蒸 |

切换菜系会同步影响:
- 食材库当地常用食材**置顶**(全部仍可见可搜)
- 菜单生成时优先使用本地食材
- 烹饪手法切换为本地代表性做法
- 子地区进一步细化口味(成都偏宫保鱼香,重庆偏水煮干煸)

### 🥬 Chapter 03 · 食材营养库

80+ 种常见食材,每项标注:

- 每 100g 生重的热量与三大宏量
- 食材分类(碳水 / 蛋白 / 脂肪 / 蔬菜)
- 当地常用区域(影响置顶顺序)
- 中/美膳食指南分组(影响指南推荐量标签)
- 常用份量参考(一碗/一颗/一份)
- 深色蔬菜标记(用于指南达标计算)

涵盖范围:
- **主食**:糙米饭、白米饭、燕麦、小米、玉米、藜麦、荞麦面、刀削面、全麦馒头、粿条、河粉、意面、全麦面包、红薯、紫薯、土豆、山药、红豆、绿豆
- **蛋白**:鸡胸/腿、瘦牛肉、猪瘦肉、鸭胸、瘦羊肉、鲈鱼、鳕鱼、三文鱼、草鱼、黄花鱼、鲫鱼、鲜虾、鱿鱼、蛤蜊、鸡蛋、蛋白、纯/脱脂牛奶、希腊酸奶、低脂奶酪、嫩/老豆腐、豆干、无糖豆浆
- **脂肪源**:牛油果、巴旦木、核桃、腰果、花生、橄榄油、亚麻籽、芝麻酱
- **蔬菜**:西兰花、菠菜、芥蓝、潮州春菜、油麦菜、通菜、上海青、茼蒿、韭菜、苋菜、苦瓜、黄瓜、番茄、茄子、冬瓜、丝瓜、白萝卜、胡萝卜、莲藕、金针菇/香菇/杏鲍菇、木耳、豆芽、秋葵、酸菜、大白菜、豆角

### 📋 Chapter 04 · 今日菜单(三种模式)

#### A. 自动生成 · 每日不同
- **种子化随机**:同一天 + 同一菜系组合下,刷新页面得到完全相同的菜单(基于日期哈希)
- 日期选择器:改日期自动换菜单
- "↻ 换一份"按钮:同一天想换搭配也行
- 三餐分配 25% / 40% / 35%,主食 + 蛋白菜 + 蔬菜菜 + 偶尔水果
- 自动微调份量逼近宏量目标
- 脂肪不足时自动补加坚果

#### B. 按食材自定义
- 左侧食材池,按菜系置顶常用,可搜索/分类筛选
- 右侧已选食材列表,克数可直接输入调整
- 三餐独立管理(早/午/晚)
- **智能推荐**:基于已选食材,自动推荐当前菜系下的菜品组合
  - 选了鸡胸 → 推荐"水煮鸡胸 / 凉拌鸡胸 / 清蒸鸡胸"
  - 选了西兰花 → 推荐"白灼西兰花 / 蒜蓉蒸西兰花 / 上汤西兰花"
- 实时合计三餐营养并对比目标

#### C. 按菜品自定义
- 60+ 道预设菜品库,按当前菜系动态生成
- 每张菜品卡显示菜名、做法、营养值
- 分类筛选:全部 / 主食 / 蛋白菜 / 蔬菜菜 / 汤品 / ★当地
- 点选菜品 → 加入指定餐次
- 实时三餐预览 + 合计

### 🍳 烹饪卡片 Modal

点击任意菜名弹出详细做法卡:

- **菜品信息**:中英文名、做法标签、所属菜系
- **核心数据**:耗时、总热量、三大宏量
- **完整原料清单**:主料精确克数 + 辅料(姜葱蒜/调料/酱汁)
- **分步做法**:每个做法都为减脂版定制
  - 水煮菜:"激而不泡",省去最后淋油可减 30% 热量
  - 麻婆豆腐:用清汤替代肉末
  - 干煸豆角:用不粘锅 + 耐心煸炒,油量减半以上
- **减脂要点**:讲清传统做法 vs 减脂版的差异

30+ 种烹饪手法均有完整步骤和贴士。

### 📖 Chapter 05 · 膳食指南达标

支持中/美两套权威膳食指南实时核对:

#### 中国指南(中国营养学会 2022 版平衡膳食宝塔,1600–2400 kcal)
12 个食物组 × 推荐摄入区间:
- 精制谷类 50–150g + 全谷物杂豆 50–150g
- 薯类 50–100g
- 深色蔬菜 ≥150g(占总蔬菜 ≥1/2) + 浅色蔬菜
- 水果 200–350g
- 畜禽肉 40–75g · 鱼虾 40–75g · 蛋 40–50g
- 奶类 300–500ml · 大豆 15–25g · 坚果 5–10g

#### 美国指南(USDA Dietary Guidelines for Americans 2020-2025,Healthy U.S.-Style 2000 kcal)
11 个食物组:
- 蔬菜 2.5 cup-eq · 水果 2 cup-eq
- 全谷物 ≥3 oz-eq / 总谷物 6 oz-eq
- 乳制品 3 cup-eq
- 蛋白质合计 5.5 oz-eq(含海鲜 ~8 oz/周)
- 油 27g

每个食物组实时显示:
- 当前菜单实际摄入量
- 推荐区间 + 进度条
- 状态徽章(✓达标 / ⌣不足 / ⚠超量)
- 综合达标率(Compliance Score)

干重/熟重已自动换算(豆腐 100g → 大豆 15g 当量、糙米饭 130g → 干重 52g 等)。

## 🛠 技术栈

- **纯 HTML / CSS / 原生 JS**,单文件 4000+ 行
- **零依赖**,只引入 Google Fonts(Cormorant Garamond + Noto Serif SC + JetBrains Mono)
- **响应式布局**:桌面 / 平板 / 移动端三栏自适应

## ⚠️ 免责声明

本工具仅作日常营养参考,**不构成医疗建议**。

- 食材营养值为生重参考,实际值因品牌/产地/烹饪损耗略有差异
- 膳食指南推荐量基于成年健康人群一般需求(1600–2400 kcal 段)
- 减脂期或特殊健康状况(糖尿病/肾病/孕期等)请咨询注册营养师
- 烹饪做法的"减脂版"经过适度改良,味道与传统版可能略有差异
